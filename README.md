# Simulador de la bodega

Simulación de eventos discretos de una bodega de distribución (Los chispitas · TecNM, Instituto Tecnológico de Tijuana).

- Simulador 3D: https://l25213877-collab.github.io/simulador-bodega/simulador.html
- Modo jurado (Hoy vs. propuesta, lado a lado): https://l25213877-collab.github.io/simulador-bodega/jurado.html
- Sin internet: descargar el repositorio y abrir `abrir_simulador.command` (Mac) o servir la carpeta con `python3 -m http.server`.
